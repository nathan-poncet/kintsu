Be told when v0.1 ships.

One message when the first release is out. Nothing before, nothing after unless you ask.

By email

The email list is not connected yet. Use the GitHub option below; it works today.

On GitHub

GitHub sends one notification per release, to the address of your account.

  1. Open github.com/nathan-poncet/kintsu.
  2. Click Watch, then Custom.
  3. Tick Releases only, then Apply.

What you get

  • One email at v0.1 with the install line and what works.
  • Your address is stored by the mailing provider only; every email has an unsubscribe link.
  • No tracking on this page, no other use of the address.
