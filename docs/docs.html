Install

One static binary, no runtime, no account. Today it builds from source; the package managers and the prebuilt binaries arrive with v0.1, and the commands below are the ones they will use.

Homebrewwith v0.1
brew install nathan-poncet/tap/kintsu
prebuilt binarywith v0.1
curl -fsSLO https://github.com/nathan-poncet/kintsu/releases/latest/download/kintsu-aarch64-apple-darwin.tar.gz
tar xzf kintsu-aarch64-apple-darwin.tar.gz && install -m 755 kintsu ~/.local/bin/

Intel Macs: x86_64-apple-darwin. Signed and notarized.

prebuilt binarywith v0.1
curl -fsSLO https://github.com/nathan-poncet/kintsu/releases/latest/download/kintsu-x86_64-unknown-linux-musl.tar.gz
tar xzf kintsu-x86_64-unknown-linux-musl.tar.gz && install -m 755 kintsu ~/.local/bin/

Static musl build, any distribution, aarch64 too. No curl | sh: you download, you look, you install.

cargo binstallwith v0.1
cargo binstall kintsu
Nix, AURlater, help welcome
nix run github:nathan-poncet/kintsu
yay -S kintsu-bin
cargo, from the repositorytoday
cargo install --git https://github.com/nathan-poncet/kintsu

Needs a Rust toolchain: rustup.rs. Builds in a second; there are no dependencies yet.

clone and buildtoday
git clone https://github.com/nathan-poncet/kintsu.git
cd kintsu && cargo install --path .
cargo, from crates.iowith v0.1
cargo install kintsu
on a server, over SSHtoday
ssh box 'cargo install --git https://github.com/nathan-poncet/kintsu'
# the daemon runs per user on the remote host; your keys stay where you put them
inside tmux or Herdrtoday
# nothing special: the hook lives in your shell; the multiplexer is where
# Kintsu reads the actual output best
as a Herdr pluginlater
herdr plugin install nathan-poncet/kintsu

2 Hook your shell

~/.zshrctoday
eval "$(kintsu init zsh)"
~/.bashrctoday
eval "$(kintsu init bash)"

Messages arrive at the next prompt and there is no ghost text: bash has no safe way to draw while readline waits. Everything else is the same.

~/.config/fish/config.fishtoday
kintsu init fish | source

3 Make it yours, when v0.1 lands

three commandswith v0.1
kintsu setup            # Ollama? a key? a CLI agent? Writes ~/.config/kintsu/config.toml
kintsu doctor           # what works, what is missing, what an answer would cost
kintsu service install  # the daemon survives logout and restarts on crash

Uninstall: remove the line from your rc file, kintsu service uninstall, delete the binary. Nothing else was touched.

Keys and commands

Everything the bubble does has a key, a word you can click, and a command.

wherekeydoes
at the prompt, empty lineTab or →accept the ghost-text fix (zsh, fish)
at the prompt^Kunfold the last bubble into the panel, or fold it
at the promptclick a wordopen the panel on that action (terminals that render OSC 8 links)
panelw f a i pWhy · Fix · Agent · Ignore · Privacy
panel⏎insert the focused suggestion in your line and fold; you press Enter again to run
panelccopy the focused suggestion
panelTab · ↑ ↓ · wheelmove focus · scroll
panelEsc or qfold
kintsu why · fix · agent · privacy · ignoreact on the last failure; alias k

kintsu mute 1han hour of nothing
