Roadmap

No dates. A version ships when every item in its list works.

  1. now

    Hooks and design

    • Hooks for zsh, bash and fish
    • Design documents: architecture, daemon, models, UI
    • The installer and this site
  2. v0.1

    The bubble

    Goal: a suggestion is shown under every failed command.

    • Daemon: one process per user, Unix socket, started on demand
    • Rule engine: command typos, wrong directory, git, Docker not running, port in use
    • Explanations (Why) through one provider layer: OpenAI-compatible, Anthropic, Ollama
    • Hand-off to a CLI agent: Claude Code, Codex, OpenCode, aider
    • Ignore and mute; no output on success or Ctrl-C
  3. v0.2

    It reads the output

    Goal: the failed command's output is captured, redacted, and shown before it is sent.

    • Output capture: tmux, Herdr, WezTerm, Kitty, iTerm2
    • Redaction of secrets; the Privacy tab shows the exact payload
    • Model-generated fixes with a confidence score; destructive commands flagged
    • Asynchronous messages in zsh and fish; clickable words (OSC 8)
  4. v0.3

    Your agent, your keys

    Goal: any provider, local or cloud, with keys in the keychain and per-task routing.

    • Keys in the OS keychain; reuse of CLI subscriptions
    • Local models: Ollama, LM Studio, llama.cpp
    • Per-task routing with privacy constraints and cost budgets
    • MCP server exposing the last failure to any agent
  5. later

    Ideas

    Rules learned from accepted fixes, team runbooks, a CI mode, PowerShell and nushell, explanations in other languages, a Herdr plugin.
