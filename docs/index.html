The command failed.
Kintsu picks it up.

A small bubble under the error, in the terminal and shell you already use. It fixes the typo, explains the trace, or hands the whole case to the AI agent you already pay for. Your models, your keys, and nothing runs without you.

$ curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh

macOS · Linux · zsh, bash, fish · MIT — the script installs the binary and hooks your shell; Homebrew, cargo and the other ways →

It's live. Click a word in the bubble, or focus the terminal and press ^K, w, f, a, i, Esc. The guided tour →

Kintsugi repairs broken pottery with gold. The crack becomes the strongest, most visible line of the piece. A failed command is a crack.

  1. 01

    A bubble, not a wall. →

    Under the failure: one gold seam, one sentence, a line of words. Tab accepts the fix already typed for you; ^K unfolds a panel with Why, Fix, Agent, Ignore and Privacy. The words are clickable. Nothing ever steals a keystroke from your prompt.

    $ gti status
zsh: command not found: gti
▎ Did you mean git status?
▎ Tab to fix · Why · Agent · Ignore · ^K more
$ git status
  2. 02

    Your agent, briefed. →

    Three test failures, one cause. Kintsu writes the case, command, output, directory, branch, last commands, secrets redacted, and launches Claude Code, Codex, OpenCode or aider in your terminal with it. Then it steps aside. No API key if the CLI already has one.

    ▎ 3 failures, one cause: the fixture token expired on Sep 1.
▎ Handing to Claude Code · 48 lines · cwd · branch feat/refresh
▎ last 10 commands · redacted: 1 token · ⏎ to start
claude-code · reading tests/fixtures/token.ts …
claude-code · npm test → 48 passed · diff ready. Commit?
  3. 03

    Your models. Your keys. Local when it must. →

    A rule for the typo. A tiny model on your machine to read the output. The cloud model you chose to explain. Your agent to fix. One file decides who answers what, and a secret spotted in the output forces local for that case. Automatically.

    localrulesunder a millisecond
    localtiny · ollamareads the output
    cloudhaiku, or yoursexplains, streams
    your accountclaude codefixes the code
  4. 04

    Never runs anything. Shows what leaves. →

    A fix is inserted in your line; you press Enter. Destructive commands are red first. The Privacy tab is the exact payload that went out, redactions highlighted. No telemetry, no account, no server of ours.

    ▎ What left the machine, to haiku:
▎ ✓ command · exit status · 14 lines of output
▎ ✓ NPM_TOKEN=npm_•••••••• redacted
▎ ✓ cwd · branch main, clean · last 10 commands
▎ ✗ environment · files · anything you did not see here
  5. 05

    Quiet. Fast. Everywhere you already are. →

    Under a millisecond on success, nothing on Ctrl-C, one bubble for the same failure twice. A resident daemon per user remembers across every tab, and answers that take longer arrive later, above your prompt, without touching the line you type. zsh, bash, fish. Any terminal. SSH, tmux, Herdr.

    $ vim scripts/build.js
$
