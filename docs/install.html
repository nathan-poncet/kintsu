Install

One line, or your way.

One static binary, no runtime, no account. The installer does everything; the other methods are here for people who like to see each step.

the installertoday
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh

# the same script, with options
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh -s -- --dir ~/bin --no-hook
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh -s -- --uninstall

Options: --dir, --version, --from-source, --no-hook, --yes, --dry-run, --uninstall. Release archives are checked against the published SHA256SUMS. Read it before you run it; it is 130 lines of plain sh.

2 Hook your shell

~/.zshrctoday
eval "$(kintsu init zsh)"
~/.bashrctoday
eval "$(kintsu init bash)"

Messages arrive at the next prompt and there is no ghost text: bash has no safe way to draw while readline waits. Everything else is the same.

~/.config/fish/config.fishtoday
kintsu init fish | source

3 Make it yours, when v0.1 lands

three commandswith v0.1
kintsu setup            # Ollama? a key? a CLI agent? Writes ~/.config/kintsu/config.toml
kintsu doctor           # what works, what is missing, what an answer would cost
kintsu service install  # the daemon survives logout and restarts on crash

Uninstall: remove the line from your rc file, kintsu service uninstall, delete the binary. Nothing else was touched.
