Install

One static binary. No runtime, no account.

One line

macOS · Linux · zsh, bash, fishtoday
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh

Installs the binary in ~/.local/bin and asks before adding one line to your shell configuration. Open a new shell. Done.

If you skipped the hook

Add the line yourself, then open a new shell.

~/.zshrc
eval "$(kintsu init zsh)"
~/.bashrc
eval "$(kintsu init bash)"

In bash, messages arrive at the next prompt and there is no ghost text. Everything else is the same.

~/.config/fish/config.fish
kintsu init fish | source

Other ways

Prebuilt binaries arrive with the first tagged release. Building from source works today.

prebuilt binary
curl -fsSLO https://github.com/nathan-poncet/kintsu/releases/latest/download/kintsu-aarch64-apple-darwin.tar.gz\ntar xzf kintsu-aarch64-apple-darwin.tar.gz && install -m 755 kintsu ~/.local/bin/

Intel Macs: x86_64-apple-darwin.

prebuilt binary
curl -fsSLO https://github.com/nathan-poncet/kintsu/releases/latest/download/kintsu-x86_64-unknown-linux-musl.tar.gz\ntar xzf kintsu-x86_64-unknown-linux-musl.tar.gz && install -m 755 kintsu ~/.local/bin/

Static build, any distribution. aarch64 too.

cargo, from the repositorytoday
cargo install --git https://github.com/nathan-poncet/kintsu

Needs a Rust toolchain: rustup.rs.

or
clone and buildtoday
git clone https://github.com/nathan-poncet/kintsu.git\ncd kintsu && cargo install --path .
on a server, over SSHtoday
ssh box 'curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh -s -- --yes'

Kintsu runs per user on the remote host; keys are read there, nothing is sent from your machine.

Inside tmux or Herdr, nothing changes: the hook runs in your shell. A Herdr plugin is planned.

Uninstall

removes the binary and the hook line
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh -s -- --uninstall

Nothing else was touched.

Installer options

For automation, a custom directory, or a shell you manage yourself.

--dir DIRinstall directory; default ~/.local/bin, or $KINTSU_INSTALL_DIR
--no-hookdo not edit any shell configuration file
--no-modeldo not install Ollama or pull qwen2.5-coder:7b; also KINTSU_NO_MODEL=1
--yesanswer yes to every question: the hook, the local model; also KINTSU_YES=1
--version vX.Y.Za specific release instead of the latest
--from-sourceskip the release, build with cargo
--dry-runprint what would happen
example: a CI job, no prompt, no rc change
curl -fsSL https://nathan-poncet.github.io/kintsu/install.sh | sh -s -- --yes --no-hook --dir /usr/local/bin

Release archives are checked against the published SHA256SUMS. The script is 130 lines of plain sh.
